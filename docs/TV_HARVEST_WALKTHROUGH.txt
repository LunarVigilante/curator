================================================================================
                           PHASE 1: HARVEST
================================================================================

Entry Point: npx tsx src/scripts/harvest-tmdb.ts --type=tv --operation=harvest

Data Flow:
  harvest-tmdb.ts → tmdb.ts:harvestTmdb() → tmdb.ts:processHarvestTask()

What Gets Fetched from TMDB:
  - Basic info: title, overview, first_air_date, status, vote_average
  - Credits: cast (with characters), created_by, crew
  - Genres & Keywords: ALL keywords (no limit - vital for classification)
  - Media: poster_path, backdrop_path, logo_path, trailer
  - Metadata: type ("Scripted", "Miniseries", "Documentary"), networks

What Gets Fetched from OMDb:
  - imdb_rating (more accurate than TMDB)
  - imdb_votes
  - rotten_tomatoes_rating
  - metacritic_rating
  - awards_text ("Won 2 Emmys. 15 wins & 20 nominations.")

Key Function: fetchTmdbDetails() [tmdb.ts:148-167]
  - Calls TMDB API with append_to_response for batch fetching
  - Normalizes response into TmdbMetadata interface

================================================================================
                        PHASE 2: CLASSIFICATION
================================================================================

3-Bucket System: detectTvBucket() [tv-show-description.ts:180-260]

Purpose: Route shows to correct AI prompt template

Detection Priority (CRITICAL - prevents misclassification):

    0a. TMDB TYPE FIELD (Strongest Signal) - FIRST CHECK
        TMDB's metadata.type field: "Scripted", "Miniseries", "Documentary"
        → "Scripted" = NARRATIVE (source of truth)
        → "Miniseries" + Documentary genre = OBSERVATIONAL (e.g., Planet Earth)
        → "Miniseries" without Documentary = NARRATIVE (e.g., Band of Brothers)
    
    0b. SCRIPTED FORCE (Negative Constraint) - SECOND CHECK
        Keywords: mockumentary, sitcom, comedy-drama, dramedy, scripted,
                  workplace comedy, single-camera, multi-camera
        → If ANY present = NARRATIVE (prevents The Office → Documentary)
    
    1. FORMAT DETECTION
        Keywords: competition, elimination, contestant, game show, host
        Genres: Game Show, Talk
        → FORMAT bucket
    
    2. OBSERVATIONAL DETECTION  
        Genres: Documentary, News
        Keywords (non-competition): following, access, behind-the-scenes
        → OBSERVATIONAL bucket
    
    3. DEFAULT → NARRATIVE

             CHARACTER ARCHETYPE TRANSLATION (Semantic Density)
================================================================================

Function: translateToArchetypes() [tv-show-description.ts:360-420]

Purpose: Replace character names with universal archetypes for cross-show
         similarity matching (e.g., "Walter White" → "Anti-Hero")

Available Archetypes:

  Protagonist Archetypes:
    - Anti-Hero: Morally ambiguous, driven by vice (Walter White, Tony Soprano)
    - Byronic Hero: Brooding, isolated, code of honor (The Witcher, Mandalorian)
    - Chosen One: Destined for greatness (Jon Snow)
    - Everyman: Ordinary person, extraordinary circumstances
    - Cynical Genius: Brilliant but abrasive (House, Sherlock)

  Supporting Archetypes:
    - Mentor, Caregiver, Trickster, Rebel, Sage
    - Straight Man vs The Fool (Jim/Michael, Abed/Troy)
    - Chaos Agent: Eccentric, disruptive (Fleabag)
    - Found Family: Ensemble dynamics (Community, Brooklyn 99)

================================================================================
                     PHASE 3: DESCRIPTION GENERATION
================================================================================

Entry: generateTvShowDescription() [tv-show-description.ts:680-980]

What Gets Generated (4-Part Structure):
  1. Premise      → Plot + protagonist + central conflict
  2. Themes       → Core themes + motifs (2-3 sentences)
  3. Tone         → Atmosphere + emotional register
  4. Style        → Visual/structural qualities
  5. SemanticSummary → Dense 2-sentence elevator pitch for embeddings

Bucket-Specific Prompts:

  NARRATIVE → Focus: Protagonist, inciting incident, dramatic arc
  FORMAT    → Focus: Competition mechanics, prize, uniqueness
  OBSERVATIONAL → Focus: Subject matter, access level, perspective

================================================================================
                        PHASE 4: TAG GENERATION
================================================================================

Entry: generateTvShowTags() [tv-show.ts:44-120]

4-Bucket Taxonomy:
  1. sub_genres (3-5)  → Niche classification: "nordic noir", "workplace sitcom"
  2. tropes (4-6)      → TV Tropes terminology: "found family", "slow burn"
  3. mood (3-5)        → Emotional signature: "cerebral", "cozy", "bleak"
  4. format (2-4)      → Structure: "anthology", "binge-worthy", "procedural"

Output: 15-20 high-density tags stored in cached_tags column

================================================================================
           PHASE 5: EMBEDDING GENERATION (Semantic Density Optimized)
================================================================================

Vector Text Builder: buildTvShowVectorText() [tv-show-description.ts:1383-1488]

"Prefix Fusion" Strategy + Token Limit Enforcement:
  1. Structural tokens FIRST (for transformer attention bias)
  2. Semantic summary SECOND
  3. 750 TOKEN LIMIT enforced (prevents "Vector Dilution")

Prefix Order (Highest Signal First):
  1. Format: SCRIPTED_SINGLE_CAM (6-label taxonomy - MOST SPECIFIC)
  2. Type: NARRATIVE (3-bucket)
  3. Lens: CRIME (genre lens)
  4. Franchise: GOLDEN_FLEECE (Save the Cat)
  5. Archetypes: "Features Anti-Hero protagonist..." (character dynamics)
  6. Pacing: serialized, binge-worthy
  7. Tone: cerebral, bleak
  8. Genre: nordic noir, crime drama
  9. Tropes: found family, slow burn
  10. Summary: [semanticSummary from description_parts]
  11. Keywords: [unique TMDB keywords not in tags]

Example Vector Text:
    Format: SCRIPTED_SINGLE_CAM | Type: NARRATIVE | Lens: CRIME | 
    Franchise: GOLDEN_FLEECE |
    Archetypes: Features Anti-Hero protagonist who descends into crime |
    Pacing: serialized, binge-worthy | Tone: cerebral, bleak |
    Genre: crime drama, prestige drama | Tropes: moral decay, transformation |
    Summary: A chemistry teacher's descent into methamphetamine manufacturing...

Embedding: Voyage-4 (1024 dimensions) via generateEmbedding() [shared.ts:280-320]

================================================================================
                          PHASE 6: BACKFILL
================================================================================

CLI: npx tsx src/scripts/backfill --category TV_SHOW --phase smart

Available Phases [config.ts:15-17]:
  - smart        → Conditional (only what's missing)
  - rehydrate    → Fresh TMDB + cached descriptions
  - full         → All phases

Smart Phase Logic [smart.ts:80-220]:
  1. Check for missing metadata → calls refreshMetadata()
  2. Check for incomplete description_parts → calls generateTvShowDescription()
  3. Check for missing tags → calls generateTags()
  4. Check for missing archetypes → calls translateToArchetypes()
  5. Check for missing franchise_type → calls classifyFranchiseType()
  6. Check for missing universe_id → calls detectAndResolveUniverse()
  7. If ANYTHING updated → regenerates embedding via buildTvShowVectorText()

Rehydrate Phase Logic [rehydrate.ts:70-195]:
  Purpose: Update ongoing/returning series with fresh stats (no LLM cost)
  
  1. Fetch fresh TMDB data (seasons, episodes, status, ratings)
  2. Use CACHED description_parts (no AI call!)
  3. Rebuild embedding text with buildTvShowVectorText() (Prefix Fusion)
  4. Re-embed with Voyage-4 only (~$0.001 per item)

   → Edit FORMAT_DETECTION constant in tv-show-description.ts
   → Add detection keywords to appropriate category array
   → Add new value to TvFormat type

   → Format: [SPINOFF_TMDB_ID, PARENT_TMDB_ID]

   → Edit MAX_VECTOR_TOKENS constant in tv-show-description.ts
   → Current: 750 tokens
